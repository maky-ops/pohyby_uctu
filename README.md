# pohyby_uctu
Semestrální práce OOP: Rozlišení pohybů na příjmy, výdaje a pohyb mezi vlastními účty

Program byl vytvořen pro Python ve verzi 3.14

Pro lepší přehlednost .csv souborů v prostředí VS Code bylo nainstalováno rozšíření Rainbow CSV. 

 -> VS Code -> Extensions -> vyhledat Rainbow CSV -> Nainstalovat

pip install matplotlib
